# Delta Lake MERGE Implementation

## Objective
This project demonstrates incremental data processing using Delta Lake by loading customer data, performing data cleaning, creating a Delta table, 
and applying the MERGE operation to update existing records and insert new records.

## Dataset
Two CSV files are used (generated by chatgpt beacuse both the csv files were not provided ):
- **customer_master.csv**
  - Initial customer dataset (500+ records)
  - Contains duplicate rows and null values for data cleaning.

- **customer_incremental.csv**
  - Incremental customer dataset (200 records)
  - Contains existing customer records for updates and new customer records for insertion.

## Workflow
1. Load the master customer CSV file.
2. Remove duplicate records and null values.
3. Create a Delta table from the cleaned master dataset.
4. Load and clean the incremental customer dataset.
5. Perform a Delta Lake MERGE operation:
   - Update existing customers.
   - Insert new customers.
6. Read the final Delta table.
7. Validate the final output by checking row counts and merge results.

## Output
- Cleaned customer data stored as a Delta table.
- Existing customer records updated.
- New customer records inserted.
- Final merged dataset validated successfully.
