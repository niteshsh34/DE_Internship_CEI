## Overview
This assignment demonstrates data cleaning, transformation, filtering, aggregation, and schema modification using Apache Spark DataFrames.

## Dataset
Since no dataset was provided, I created a custom **sales_data.csv** dataset specifically for this assignment. The dataset was designed to align with all assignment requirements and includes various real-world scenarios such as duplicate records, null values, empty fields, different regions, product categories, timestamps, and store information to perform comprehensive Spark DataFrame operations.

## Tasks Performed
- Removed duplicate records
- Handled null and inconsistent values
- Applied filtering conditions
- Performed grouping and aggregations
- Modified DataFrame schema
- Built a complete data processing pipeline using PySpark
